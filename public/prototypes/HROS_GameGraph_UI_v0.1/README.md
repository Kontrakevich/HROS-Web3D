# HROS Game Graph UI v0.1

Высококонтрастный интерактивный прототип игрового интерфейса HROS.

## Реализовано

1. Главный экран построен вокруг графа взаимосвязей пользователя.
2. Каждая связь подписана прямо на графе.
3. Наведение мыши или нажатие на связь показывает её характеристики.
4. Двойной клик по связи открывает страницу связи.
5. Страница связи содержит название, характеристики и историю формирования.
6. Рядом с графом расположен интерфейс пользователя: аватар, ИИ-дневник и быстрые действия.
