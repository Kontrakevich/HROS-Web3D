# HROS Moment Engine Skill

## Назначение
Создание, изменение, финализация и удаление значимых моментов с явным разделением исходных данных, пользовательской оценки и вычисляемого влияния на отношения.

## Входы
- `title`, `date`, `period`, `description`, `meaning`, `place`;
- `participantIds`;
- `emotions`;
- `significance` 0–100;
- `relationshipEffect.closeness|trust|tension` от -1 до 1;
- `source` и метаданные вложений.

## Выходы
- версионируемая сущность `Moment`;
- журнал ревизий;
- обновлённый Snapshot;
- диагностическое событие без секретов.

## Ограничения
- неизвестные участники блокируют запись;
- финализированная запись не переписывает историю;
- бинарные вложения на GitHub Pages не сохраняются: хранится только безопасная метаинформация или внешняя ссылка;
- AI-оценки обязаны маркироваться в `source.kind`.

## Критерии качества
- CRUD и финализация покрыты API-тестами;
- интерфейс проходит Chromium и WebKit smoke tests;
- значения влияния валидируются диапазоном -1…1;
- удаление не нарушает ссылки Snapshot.

## Диагностика
Фиксируются операция, тип сущности, версия, длительность API-запроса и trace ID. Секреты и содержимое бинарных файлов не журналируются.

## Совместимость с n8n
JSON-контракт расположен в `skills/moment-engine/moment.schema.json`. Операции API детерминированы и пригодны для HTTP Request nodes.
