# HROS Game Graph UI v0.1

Статус: тестовый интерфейсный прототип.

## Назначение

Прототип проверяет новую иерархию первого экрана HROS:

```text
Граф взаимосвязей пользователя
→ подписи связей
→ характеристики по hover/tap
→ страница связи по double click
→ история формирования связи
```

На первом экране одновременно доступны:

- игровой аватар пользователя;
- ИИ-дневник;
- быстрые действия для добавления связи и фиксации момента.

## UX-контракт

1. Граф является главным визуальным объектом первого экрана.
2. Каждая связь имеет собственное название.
3. Hover на desktop и tap на mobile раскрывают характеристики связи.
4. Double click открывает страницу связи.
5. Страница связи хранит название, характеристики и историю формирования.
6. Яркость и контраст не должны ухудшать читаемость подписей и деталей.

## Ограничение

Текущие данные внутри прототипа демонстрационные и не подключены к `hros.snapshot.v1`. Следующий этап — перенести UX в основной HROS COMMAND и связать граф с Repository Service.
